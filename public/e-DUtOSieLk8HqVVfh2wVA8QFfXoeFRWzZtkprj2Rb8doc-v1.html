AsyrofOTP API

Panduan integrasi OTP virtual number. Autentikasi pakai API key, gak pakai OAuth yang ribet.

Ambil API Key Baca Authentication
Base URLhttps://asyrofotp.vercel.app/api/v1
Formatapplication/json
Rate Limit30 req/menit (order), 60 req/menit (baca)

Introduction

API AsyrofOTP pakai gaya REST dengan payload JSON. Semua respons sukses bakal ada field ok: true. Kalau gagal, bakal ada field error sama HTTP status yang sesuai.

Base URL

Base URL
https://asyrofotp.vercel.app/api/v1

Flow standar

  1. Cek saldo — GET /me
  2. Pilih layanan — GET /services?server=ekonomi
  3. Pilih negara — GET /countries?server=ekonomi&service=wa
  4. Cek harga & stok — GET /prices?server=ekonomi&service=wa&country=id
  5. Order — POST /order (saldo auto-deduct)
  6. Polling OTP — GET /order/:otp_id tiap 5 detik, atau pakai webhook

Authentication

Semua endpoint butuh API key. Formatnya: asyrofotp-XXXXXXXXXXXXXXXX (16 karakter).

Dapatkan API key

Buka dashboard → bagian API Key → Rotate API Key. Atau lewat endpoint:

Response GET /api/user/api-key
{
  "api_key": "asyrofotp-aB3xY9kLmN2pQr7s",
  "created_at": "2026-01-15T08:30:00.000Z",
  "last_used_at": null
}

Kirim API key di request

Ada 3 cara, pilih salah satu:

Authorization Bearer (recommended)
Authorization: Bearer asyrofotp-aB3xY9kLmN2pQr7s
X-API-Key header
X-API-Key: asyrofotp-aB3xY9kLmN2pQr7s
Query param (kurang aman, cuma buat debug)
GET /api/v1/me?api_key=asyrofotp-aB3xY9kLmN2pQr7s
⚠️ Jangan expose API key di frontend

Key ini rahasia. Kalau bocor, orang lain bisa order pakai saldo kamu. Rotate dari dashboard jika bocor.

💡 Price lock

Harga yang lo lihat dari /prices di-lock. Kalau langsung POST /order pakai id yang sama, lo bayar sesuai harga itu — kecuali harga provider naik di antara preview & order (maka dapat error PROVIDER_PRICE_JUMPED).

Webhooks

Daripada polling terus, lo bisa daftar webhook. AsyrofOTP akan POST ke URL kamu setiap ada event.

Daftar webhook

Buka dashboard profile → section Webhook → Tambah Webhook. Atau via API:

curl (butuh JWT, bukan API key)
curl -X POST https://asyrofotp.vercel.app/api/user/webhooks \
  -H "Authorization: Bearer <JWT>" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://domain-kamu.com/webhook",
    "events": ["order.otp_received", "deposit.success"]
  }'

Signature & Retry

Verifikasi signature

Setiap request punya header X-Asyrof-Signature berisi sha256=HMAC_SHA256(rawBody, secret). Secret bisa dilihat di dashboard (tombol Copy Secret / Rotate).

Node.js
const crypto = require("crypto");

const secret = "whsecao-xxxxx";
const rawBody = req.rawBody;  // string, bukan parsed JSON

const expected = "sha256=" + crypto
  .createHmac("sha256", secret)
  .update(rawBody)
  .digest("hex");

if (req.headers["x-asyrof-signature"] !== expected) {
  return res.status(401).end();
}
💡 Pakai raw body

Kalau lo parse JSON dulu lalu re-stringify, HMAC-nya beda (urutan key / whitespace beda). Simpan req.rawBody (Express: express.json({ verify: (req, res, buf) => req.rawBody = buf })).

Retry

Kalau URL kamu tidak return 2xx, AsyrofOTP retry 3× dengan delay 1.5s, 3s, 4.5s. Total window ~9 detik. Kalau 3× gagal, event dibuang (tidak di-queue). Log bisa dicek di dashboard.

Rotate secret

Kalau secret bocor, rotate dari dashboard. Secret baru langsung aktif, yang lama tidak valid.
